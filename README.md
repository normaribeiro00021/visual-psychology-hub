# Visual Psychology Hub

Crie uma aplicação web completa e responsiva chamada:

PSICODIAGNÓSTICO VISUAL

Ela será uma ÁREA DE MEMBROS PREMIUM para alunos e compradores de materiais digitais de Psicologia, com experiência visual inspirada em plataformas modernas de streaming, como grandes serviços de filmes e séries, mas SEM copiar layouts, logos ou identidade visual de nenhuma marca.

O objetivo é fazer o usuário sentir que entrou em uma biblioteca premium de conteúdos visuais, e NÃO em uma área tradicional de cursos.

============================
1. CONCEITO PRINCIPAL
============================

A plataforma deve funcionar como uma “biblioteca visual de Psicologia”.

O usuário deve poder:

- acessar os materiais que comprou;
- continuar de onde parou;
- navegar por coleções;
- visualizar capas e cards premium;
- abrir PDFs e materiais;
- favoritar conteúdos;
- identificar materiais novos;
- visualizar atualizações;
- acessar bônus;
- descobrir outros produtos disponíveis para compra;
- comprar novos materiais através de uma vitrine interna;
- instalar a plataforma no celular como PWA.

A experiência deve ser extremamente visual.

Evitar completamente aparência de:
- plataforma de curso genérica;
- Moodle;
- dashboard corporativo;
- lista simples de arquivos.

A referência conceitual é uma experiência de streaming premium aplicada a materiais educacionais.
